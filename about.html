📱📱📱학생 기기주소 접속 → PIN 4자리

🖥️선생님 화면프로젝터로 띄우기

🧑‍🎓 학생

  1. 게임 주소 접속
  2. 학급 PIN 4자리 입력 (닉네임은 자동)
  3. 선생님이 ▶ 누르면 시작
  4. 끝나면 🏆 리더보드에서 내 순위 확인

🧑‍🏫 선생님

  1. 교사용 대시보드 → ＋ 새 방 만들기
  2. 화면에 뜬 PIN을 학생에게 보여 주기
  3. ▶ 게임 시작 → 실시간 리더보드 · 학급 신뢰도 · 🚨 알림 확인
  4. 📊 토론 화면 → 우리 반 통계 + 토론 질문
  5. 🔁 새 판 → 2회차 도전
